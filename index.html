Interpolasi Lanjar

f(x) = b₀ + b₁(x - x₀)

Interpolasi linear menggunakan 2 titik data. Metode paling sederhana yang menghasilkan garis lurus.

2 Titik Data

Interpolasi Kuadratik

f(x) = b₀ + b₁(x-x₀) + b₂(x-x₀)(x-x₁)

Interpolasi orde-2 menggunakan 3 titik data. Menghasilkan kurva parabola yang lebih akurat.

3 Titik Data

Interpolasi Kubik

f(x) = b₀ + b₁(x-x₀) + ... + b₃(x-x₀)(x-x₁)(x-x₂)

Interpolasi orde-3 menggunakan 4 titik data. Kurva lebih fleksibel dengan titik belok.

4 Titik Data

Polinom Newton

Pₙ(x) = Σ bₖ · Π(x - xⱼ)

Interpolasi orde-N menggunakan jumlah titik tak terbatas. Metode paling umum dan fleksibel.
